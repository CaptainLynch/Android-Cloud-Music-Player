# AD-011: 心动模式/智能播放作为独立功能模块

**日期**: 2026-05-18
**状态**: 已接受
**决策**: 心动模式/智能播放作为独立功能模块实现，与现有播放逻辑解耦

---

## 背景

迭代 13 Part B 需求：基于当前歌曲智能推荐相关歌曲播放。

## 原因

1. **解耦**: 智能推荐逻辑不应耦合在 MusicPlayerManager 中，避免播放器核心复杂度增加
2. **可扩展性**: 独立模块便于后续接入其他推荐源（不仅是网易云）
3. **可测试性**: 独立 ViewModel 和 Repository 便于单元测试

## 影响

- 新增数据模型（智能推荐相关）
- 新增 API 接口（网易云推荐接口）
- 新增 ViewModel 逻辑（推荐歌曲管理）
- 新增 UI 按钮 + 智能列表展示
- 不修改 MusicPlayerManager 核心逻辑

## 替代方案

| 方案 | 评估 | 结果 |
|------|------|------|
| 将推荐逻辑集成到 MusicPlayerManager | 播放器过于复杂，难以测试 | 放弃 |
| **独立模块，通过接口与播放器交互** | 解耦清晰，便于扩展 | **采纳** |

## 模块边界

```
SmartPlayModule (独立)
  ├── SmartPlayViewModel (管理推荐状态)
  ├── SmartPlayRepository (调用推荐 API)
  └── → MusicPlayerManager (通过标准接口添加歌曲到队列)
```
